# Kriti Tyagi - Portfolio Website

Personal portfolio website showcasing skills, projects, and experience.

## Features
- Responsive design
- Smooth scrolling navigation
- Projects showcase
- Contact section
- Modern UI with gradient backgrounds

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Sections
1. **Home** - Hero section with call-to-action
2. **About** - Bio and skills
3. **Projects** - Showcase of projects (Face Detection, Calculator, etc.)
4. **Contact** - Links to email, GitHub, LinkedIn

## How to View
Open `index.html` in your browser or visit the live site.
